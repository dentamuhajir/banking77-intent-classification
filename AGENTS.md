# Aturan kerja proyek Banking77

- Simpan kode proyek di repo ini. Gunakan satu commit lokal untuk satu perubahan bertujuan jelas setelah memeriksa hasilnya. Pesan commit menyebut perubahan secara spesifik.
- Gunakan satu `LOGBOOK.md` di root repo untuk keputusan metode, hasil eksperimen, dan bahan bimbingan. Tulis tanggal, keputusan atau hasil, alasan atau bukti, serta lokasi artefak bila ada. Sertakan entri dan perubahan terkait dalam commit yang sama. Perbaikan rutin cukup dijelaskan di pesan commit.
- Simpan berkas mentah, CSV hasil persiapan, dan model di Google Drive. Simpan checksum, pemetaan label, indeks split, dan ringkasan audit di Git.
- Kedua model memakai indeks fitting dan validasi yang sama. Pelajari kosakata TF-IDF hanya dari fitting. Gunakan test resmi untuk evaluasi performa setelah keputusan model dibekukan.
